# crawler-cli
CLI-инструмент на Go для асинхронного обхода списка сайтов и построения дерева
найденных страниц 
 
## Возможности
 
- обход нескольких стартовых URL параллельно, с ограничением на глубину;
- ссылки собираются только в пределах домена соответствующего стартового URL;
- не более 10 одновременных HTTP-запросов;
- обход построен на goroutine + channel;
- отдельный таймаут на запрос и общий таймаут на весь обход;
- пропуск редиректов, не-HTML-ответов и недоступных страниц;
- уже посещённые URL не запрашиваются повторно;
- graceful shutdown по `Ctrl+C` через `context.Context`;
- ошибки и HTTP-статусы пишутся в отдельный лог-файл;
- результат сохраняется в JSON-файл.
## Требования
 
- Go 1.26 или новее.
## Сборка
 
```bash
make build
```
 
Соберёт бинарник в `build/crawler`.
 
Собрать вручную, без `make`:
 
```bash
go build -o build/crawler cmd/app/main.go
```
 
## Запуск
 
```bash
./build/crawler \
  --urls https://google.com,https://example.com \
  --depth 3 \
  --timeout 2m \
  --request-timeout 10s \
  --output result.json \
  --log crawler.log
```
 
Либо через `go run`, без предварительной сборки:
 
```bash
go run ./cmd/app \
  --urls https://example.com \
  --depth 2
```
 
 
## Флаги
 
| Флаг               | Обязателен | По умолчанию   | Описание                                                                |
|---------------------|:----------:|----------------|------------------------------------------------------------------|
| `--urls`            | да         | -              | Список стартовых URL через запятую, без пробелов                 |
| `--depth`           | нет        | `2`            | Максимальная глубина обхода                                      |
| `--timeout`         | нет        | `2m`           | Общий таймаут выполнения всего обхода                            |
| `--request-timeout` | нет        | `10s`          | Таймаут одного HTTP-запроса                                      |
| `--output`          | нет        | `output.json`  | Путь к файлу с результатом обхода                                 |
| `--log`             | нет        | `crawler.log`  | Путь к файлу лога                       |
| `--log-level`       | нет        | `info`         | Уровень логирования файла (`debug`, `info`, `warn`, `error`) |
| `--go`              | нет        | `10`           | Количество одновременно работающих goroutine  |
 
Значения `timeout` и `request-timeout` задаются в формате Go `time.Duration`
(например, `10s`, `2m`, `1h30m`).
 
## Формат результата
 
Результат обхода сохраняется в файл, указанный флагом `--output`, в виде дерева:
 
```json
[
  {
    "resource": "https://google.com",
    "title": "Google",
    "links": [
      {
        "resource": "https://google.com/about",
        "title": "About Google",
        "links": []
      }
    ]
  }
]
```
 
## Остановка обхода
 
`Ctrl+C` во время выполнения запускает graceful shutdown: текущие запросы
завершаются, уже собранное дерево дописывается в `--output`, после чего процесс
завершается.
